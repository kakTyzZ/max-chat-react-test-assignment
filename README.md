# MAX Chat — тестовое задание React

Отдельный проект для тестового задания на позицию фронтенд-разработчика React. Сейчас в репозитории находятся проектный документ и план; приложение ещё не реализовано.

- [Design Document](DESIGN.md)
- [План реализации](PLAN.md)
- [Оригинал задания](https://drive.google.com/file/d/1Ut39kkIs0QK-swnCsIPJc6pNqVIVGOD2/view)

## Цель

Сделать минимальный веб-чат для MAX: подключение собственного инстанса GREEN-API, создание чата по номеру, отправка и получение текстовых сообщений. Интерфейс ориентируется на [веб-версию MAX](https://web.max.ru/) без копирования лишних функций.

Инструкция локального запуска появится вместе с приложением. Секреты и реальные учётные данные в репозиторий не добавляются.
